About Me

I'm a data analyst focused on Python and SQL — building interactive dashboards, SQL-backed analysis, and applied AI tooling end to end, from raw data through deployed, decision-ready insight tools.

I've shipped an end-to-end Python → SQL → Power BI pipeline analyzing Kansas property tax policy, a live dashboard exploring 39,000+ federal aviation safety records, and a full-cycle personal finance analytics tool with SQL analysis and forecasting. I also build production AI integrations — a retrieval-augmented generation pipeline grounded in OpenAI's API and vector search, and a LangGraph tool-calling agent — combining traditional analytics with applied AI. That range is backed by 10+ deployed full-stack applications (Django, PostgreSQL, real-time architecture), giving me engineering depth most analyst candidates don't bring to the table.

Before data, I spent time as an FAA-certified Airframe mechanic — work that trained me to follow documented procedure precisely and stay accountable when mistakes have real consequences. That discipline carries directly into how I validate and document my analysis now, and shows up literally in my FAA aviation incident analysis dashboard.

I came to programming self-taught, then formalized it through a Computer Science degree I'm completing at the University of Maryland Global Campus. I'm seeking a remote Data Analyst role where I can turn data into decisions and keep growing fast.
